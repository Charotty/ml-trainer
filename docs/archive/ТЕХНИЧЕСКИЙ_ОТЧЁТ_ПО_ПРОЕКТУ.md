## 🎯 Общая цель и постановка задачи

### Полное описание задачи проекта
Проект предсказывает смещение почек при переходе пациента из положения на спине (supine) в положение на боку (lateral) и планирует оптимальные позиции троакаров для лапароскопической хирургии с использованием AR-навигации.

### Конечная цель системы
- Предсказать координаты трёх точек почки (upper, middle, lower) в положении на боку
- Рассчитать оптимальные позиции троакаров для лапароскопического доступа
- Обеспечить точность предсказания ≤ 10 мм для безопасного проведения операции

### Где и как используется
- **Лапароскопическая хирургия почек**
- **AR-навигация** в реальном времени во время операции
- **Планирование** предоперационного доступа

### Ограничения системы
- **Отсутствие GPU:** все вычисления на CPU
- **Ограничения по времени:** inference < 2 секунд
- **Ограничения по данным:** малый датасет (43 пациента)
- **Клинические требования:** безопасность > точность

### Успешный результат
- **MAE ≤ 10 мм** по всем осям
- **Success rate > 85%** (предсказания с ошибкой < 10 мм)
- **95% ошибок < 15 мм**
- **Время inference < 2 секунд**

## 📊 Описание данных

### 2.1 Общая структура датасета

**Всего пациентов:** 43
- **Train:** 27 пациентов
- **Validation:** 6 пациентов  
- **Test:** 10 пациентов

**Источники данных:**
- **CSV/Excel файлы:** Выборка - 50.xlsx, Смещение доп - 5.xlsx, Смещение почек - 2.xlsx, Смещение почек 15.01.xlsx
- **DICOM файлы:** для извлечения дополнительных признаков
- **Формат:** CSV для ML, DICOM для feature extraction

**Парные данные (paired):**
- Пациенты с измерениями в обоих положениях (supine + lateral)
- Используются для обучения трансформации

**Непарные данные (unpaired):**
- Измерения только в одном положении
- Используются для регуляризации

### 2.2 Полный список признаков (118 всего)

**Демографические признаки:**
- `sex_x`, `sex_y`: пол (0=женский, 1=мужской)
- `age_x`, `age_y`: возраст в годах
- `bmi_x`, `bmi_y`: индекс массы тела (кг/м²)
- `body_type_x`, `body_type_y`: телосложение (0=норма, 1=астеник, 2=гипер)

**Координаты почек (supine):**
- `X_upper_supine`, `Y_upper_supine`, `Z_upper_supine`
- `X_middle_supine`, `Y_middle_supine`, `Z_middle_supine`
- `X_lower_supine`, `Y_lower_supine`, `Z_lower_supine`
- Единицы: **миллиметры (мм)**

**Координаты почек (lateral):**
- `X_upper_lateral`, `Y_upper_lateral`, `Z_upper_lateral`
- `X_middle_lateral`, `Y_middle_lateral`, `Z_middle_lateral`
- `X_lower_lateral`, `Y_lower_lateral`, `Z_lower_lateral`

**Смещения (delta) - целевые переменные:**
- `delta_X_upper`, `delta_Y_upper`, `delta_Z_upper`
- `delta_X_middle`, `delta_Y_middle`, `delta_Z_middle`
- `delta_X_lower`, `delta_Y_lower`, `delta_Z_lower`

**Анатомические признаки из DICOM:**
- `body_volume_cm3`: объём тела
- `fat_volume_cm3`: объём жировой ткани
- `bone_volume_cm3`: объём костной ткани
- `fat_ratio`: соотношение жировой ткани
- `body_width_mm_median`: медианная ширина тела
- `body_depth_mm_median`: медианная глубина тела
- `body_com_x/y/z_mm`: центр масс тела
- `spine_center_x/y/z_mm`: центр позвоночника
- `spine_to_skin_*_mm_median`: расстояния от позвоночника до кожи

**Признаки почек:**
- `kidney_left_upper_x/y/z`: координаты левой почки
- `kidney_left_middle_x/y/z`: средние точки левой почки
- `kidney_left_lower_x/y/z`: нижние точки левой почки
- `kidney_left_vs_body_center_x/y`: смещение относительно центра тела
- `kidney_left_vs_spine_center_x/y`: смещение относительно позвоночника
- `kidney_left_axis_vector_x/y/z`: вектор ориентации
- `kidney_left_distance_to_skin_mm`: расстояние до кожи
- `kidney_left_bbox_width/height_mm`: размеры bounding box
- `kidney_left_volume_cm3`: объём почки
- `kidney_left_length_mm`: длина почки
- Аналогичные признаки для правой почки

**Engineered признаки:**
- `kidney_length_supine`: длина почки в положении на спине
- `X_centroid_supine`, `Y_centroid_supine`, `Z_centroid_supine`: центр масс почки
- `kidney_angle_xy`: угол ориентации почки в плоскости XY

### 2.3 Система координат

**Текущая система:**
- **Origin:** левый верхний угол DICOM изображения
- **Направление осей:**
  - **X:** слева направо (медиально-латерально)
  - **Y:** спереди назад (антеро-постериорно)
  - **Z:** сверху вниз (кранио-каудально)
- **Единицы:** миллиметры (мм)

**Нормализация:**
- Координаты не нормализуются, используются абсолютные значения в мм
- Scaling применяется только к ML признакам через StandardScaler

**Различия между положениями:**
- **Supine:** пациент на спине
- **Lateral:** пациент на боку
- Система координат остаётся постоянной

### 2.4 Качество данных

**Обработка пропусков:**
- Удалено 86 дубликатов
- Удалено 10 строк с пропусками в критичных колонках
- Удалено 9 выбросов (> 3 стандартных отклонений)
- Пропуски в некритичных колонках заполнены медианой

**Выбросы:**
- Обнаружены и удалены значения > 3σ
- В основном в координатах почек

**Примеры некорректных данных:**
- Отрицательные значения там, где они невозможны
- Слишком большие значения координат (> 1000 мм)

### 2.5 Соответствие пациентов (critical)

**Сопоставление supine ↔ lateral:**
- Используется ФИО пациента для сопоставления
- Нормализация имён через `_normalize_name()`
- Удалены неалфавитные символы, приведены к нижнему регистру

**Ошибки сопоставления:**
- Найдены и исправлены расхождения в именах
- Использована эвристика для нечёткого сопоставления

**Решение проблемы несовпадений:**
- Стандартизация имён через регулярные выражения
- Замена ё → е
- Удаление пробелов и спецсимволов

## ⚙️ Preprocessing Pipeline

### Полный pipeline обработки данных

1. **Загрузка данных**
   - Чтение CSV файлов
   - Объединение датасетов
   - Проверка целостности

2. **Очистка данных**
   - Удаление дубликатов
   - Обработка пропусков
   - Удаление выбросов

3. **Feature Engineering**
   - Создание engineered признаков
   - Вычисление центров масс
   - Расчёт геометрических характеристик

4. **Нормализация**
   - StandardScaler для ML признаков
   - MedianImputer для пропусков

### Используемые методы

**Scaling:**
- `StandardScaler` из sklearn
- Нормализация на train данных, применение к val/test

**Обработка пропусков:**
- `MedianImputerKeepAll` - кастомный imputer
- Заполнение медианой или 0.0 если все значения NaN

### Train vs Inference pipeline
**Train:**
- Full preprocessing с fit()
- Сохранение scaler и imputer

**Inference:**
- Только transform() без fit()
- Использование сохранённых артефактов

## 🤖 ML-модель

### 5.1 Постановка задачи
**Что предсказывает модель:**
- Абсолютные смещения (delta) для 9 координат
- `delta_X/Y/Z_upper/middle/lateral`

**Входы модели:**
- 98 признаков из `feature_names.json`
- Демография + координаты supine + анатомия

**Выходы модели:**
- 9 delta значений в мм
- Смещение каждой точки почки по каждой оси

### 5.2 Используемые модели

**Random Forest:**
- `RandomForestRegressor` с `MultiOutputRegressor`
- Параметры: `n_estimators=100`, `max_depth=15`
- Причина выбора: устойчивость к переобучению, интерпретируемость

**XGBoost:**
- 9 отдельных моделей для каждой target переменной
- Параметры: `n_estimators=200`, `learning_rate=0.05`, `max_depth=6`
- Причина выбора: высокая точность, работа с нелинейностью

**Linear Regression (baseline):**
- `LinearRegression` с `MultiOutputRegressor`
- Для сравнения и как baseline

**Ensemble:**
- Weighted average RF + XGBoost
- Веса: RF=0.5, XGBoost=0.5
- Причина: комбинация сильных сторон обеих моделей

### 5.3 Обучение

**Размер датасетов:**
- Train: 27 пациентов
- Validation: 6 пациентов
- Test: 10 пациентов

**Метод разделения:**
- Случайное разделение 64%/16%/20%
- Stratified split по полу если возможно

**Cross-validation:**
- Используется validation set
- RandomizedSearchCV для RF оптимизации

**Параметры моделей:**
- RF: оптимизированные через RandomizedSearchCV
- XGBoost: early_stopping на validation
- Ensemble: веса подобраны на validation

### 5.4 Результаты

**Метрики на validation:**
- **Linear Regression:** MAE = 16.56 мм
- **Random Forest:** MAE = 9.18 мм
- **XGBoost:** MAE = 10.63 мм
- **Ensemble:** MAE = 9.86 мм

**Результаты по осям (Random Forest):**
- **X ось:** 3.52-7.43 мм (лучшая точность)
- **Y ось:** 9.75-15.71 мм (средняя точность)
- **Z ось:** 7.77-11.27 мм (хорошая точность)

**Распределение ошибок:**
- Наименьшие ошибки: X_upper (3.52 мм)
- Наибольшие ошибки: Y_lower (15.71 мм)
- Средняя MAE по всем осям: 9.18 мм

**% предсказаний < 5 мм:**
- X ось: ~60-70%
- Y ось: ~30-40%
- Z ось: ~50-60%

## 📉 Ошибки и проблемы модели

### Где модель ошибается
**Наибольшие ошибки:**
- Y_lower: 15.71 мм (нижняя точка по оси Y)
- Y_middle: 10.11 мм (средняя точка по оси Y)
- Z_lower: 11.27 мм (нижняя точка по оси Z)

**Причины ошибок:**
- Маленький датасет (27 пациентов)
- Сложность предсказания смещений по оси Y
- Индивидуальные анатомические особенности

### Примеры плохих предсказаний
- Пациенты с экстремальными значениями ИМТ
- Пациенты с аномальным положением почек
- Пациенты с большими опухолями

### Возможные причины ошибок
- Недостаточное разнообразие в данных
- Сложные нелинейные зависимости
- Шум в измерениях координат

### Переобучение
- Train MAE = 2.99 мм vs Val MAE = 9.18 мм
- Разница указывает на лёгкое переобучение
- Ensemble помогает снизить переобучение
