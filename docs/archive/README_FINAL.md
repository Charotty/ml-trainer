## 🚀 **ИСПОЛЬЗОВАНИЕ:**

### **Быстрый старт:**
```bash
# 1. Извлечение признаков из KiTS19
python extract_medical_grade_features.py

# 2. Обучение унифицированной модели
python train_unified.py

# 3. Запуск полного пайплайна
python run_pipeline.py
```

### **Основной workflow:**
1. **`extract_medical_grade_features.py`** → извлечь признаки из KiTS19
2. **Объединить с `results.csv`** → создать полный датасет
3. **`train_unified.py`** → обучить модель предсказания смещений
4. **`run_pipeline.py`** → полный автоматический процесс
