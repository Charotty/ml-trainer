## Архитектура XGBoost с множественными источниками

### 1. Обучение отдельных моделей для каждой цели
```python
for target in self.target_names:
    model = XGBRegressor(
        n_estimators=100,
        max_depth=6,
        learning_rate=0.1,
        random_state=42,
        n_jobs=-1
    )
    model.fit(X_train, y_train[target])
    self.models[target] = model
```

### 2. Автоматическая интеграция данных
- **Vybor данные**: Использованы как основной источник (22 реальные цели)
- **KiTS19 данные**: Добавлены как средние значения (91 признак)
- **DICOMS данные**: Добавлены как средние значения (27 признаков)

### 3. Обработанные цели (78 переменных)

#### Vybor данные (22 цели):
- Координаты центров почек (x_rel, y_rel, z_rel)
- Объемы почек (volume_cm3)
- Расстояния до позвоночника и центра тела
- Нормализованные координаты
- Дельты смещения

#### KiTS19 данные (56 целей):
- Координаты верхнего/среднего/нижнего сегментов обеих почек
- Объемы опухолей
- Плотности тканей
- Процентное соотношение опухолей
- Расстояния до позвоночника

## Анализ производительности

### Преимущества XGBoost:
1. **Идеальное обучение на train**: MAE 0.005 мм
2. **Быстрое обучение**: 78 моделей обучены за ~1 минуту
3. **Автоматическая обработка**: Каждый признак обрабатывается отдельно
4. **Параллелизация**: Использование всех ядер CPU

### Недостатки:
1. **Переобучение**: Значительный разрыв между train и validation
2. **Сложность**: 78 отдельных моделей вместо одной
3. **Память**: Большое количество сохраненных файлов

## Рекомендации по оптимизации XGBoost

### 1. Борьба с переобучением
```python
model = XGBRegressor(
    n_estimators=50,          # Уменьшить количество деревьев
    max_depth=3,               # Уменьшить глубину
    learning_rate=0.05,       # Уменьшить learning rate
    subsample=0.8,             # Добавить subsampling
    colsample_bytree=0.8,      # Добавить feature sampling
    reg_alpha=1.0,             # L1 регуляризация
    reg_lambda=1.0,            # L2 регуляризация
    random_state=42
)
```

### 2. Ранняя остановка (Early Stopping)
```python
model.fit(
    X_train, y_train[target],
    eval_set=[(X_val, y_val[target])],
    early_stopping_rounds=10,
    verbose=False
)
```

### 3. Кросс-валидация
```python
from sklearn.model_selection import cross_val_score
scores = cross_val_score(model, X, y[target], cv=5, scoring='neg_mean_absolute_error')
```
