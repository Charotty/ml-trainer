# Техническая документация модели предсказания смещения почек

## 1. Обзор модели

### 1.1 Назначение
Модель предсказывает смещение почек при изменении положения пациента с supine (на спине) в другие позиции. Модель разработана для использования в лапароскопической хирургии для планирования положения троакаров.

### 1.2 Архитектура
- **Тип**: Оптимизированный адаптивный ансамбль
- **Базовые модели**: RandomForest, Lasso, Ridge, GradientBoosting
- **Оптимизация весов**: scipy.optimize (метод L-BFGS-B)
- **Количество признаков**: 51 (23 базовых + 13 инженерных + 15 cross-features)
- **Количество целей**: 6 (смещение по X, Y, Z для левой и правой почки)

### 1.3 Производительность
- **Средняя MAE**: 2.140 мм
- **Средний R²**: 0.139
- **Точность <5мм**: 89.2%
- **Точность <10мм**: 97.6%
- **Улучшение над стандартным ансамблем**: +3.2%

## 2. Данные для обучения

### 2.1 Источники данных
- **DICOMS**: Медицинские изображения с DICOM метаданными
- **Vybor**: Унифицированные признаки из клинических данных
- **KiTS19**: Медицинские данные соревнования KiTS19

### 2.2 Объем данных
- **Обучающая выборка**: 239 случаев
- **Валидационная выборка**: 68 случаев
- **Итого**: 307 случаев

### 2.3 Предобработка данных
- **Масштабирование**: StandardScaler
- **Заполнение пропусков**: SimpleImputer (медиана)
- **Разделение**: 80% train, 20% test
- **Валидация**: 5-fold cross-validation

### 3.2 Инженерные признаки (13 шт.)

| Признак | Формула | Описание |
|---------|----------|----------|
| body_ratio | body_width_mm / body_depth_mm | Отношение ширины тела к глубине |
| kidney_distance_lr | |kidney_left_center_x_rel - kidney_right_center_x_rel| | Расстояние между почками |

| kidney_right_volume_norm | kidney_right_volume_cm3 / body_width_mm | Объем правой почки, нормализованный на ширину тела |
| kidney_left_length_norm | kidney_left_length_mm / body_width_mm | Длина левой почки, нормализованная на ширину тела |
| kidney_right_length_norm | kidney_right_length_mm / body_width_mm | Длина правой почки, нормализованная на ширину тела |
| volume_asymmetry | kidney_left_volume_cm3 - kidney_right_volume_cm3 | Разница объемов левой и правой почек |
| length_asymmetry | kidney_left_length_mm - kidney_right_length_mm | Разница длин левой и правой почек |
| spine_distance_asymmetry | kidney_left_to_spine_distance - kidney_right_to_spine_distance | Асимметрия расстояний до позвоночника |
| body_center_asymmetry | kidney_left_to_body_center_distance - kidney_right_to_body_center_distance | Асимметрия расстояний до центра масс |
| kidney_left_to_spine_ratio | kidney_left_to_spine_distance / body_width_mm | Отношение расстояния до позвоночника к ширине тела |
| kidney_right_to_spine_ratio | kidney_right_to_spine_distance / body_width_mm | Отношение расстояния до позвоночника к ширине тела |
| patient_position_encoded | 1 (supine) | Кодированное положение пациента |

### 3.3 Cross-features (15 шт.)

| Признак | Формула | Описание |
|---------|----------|----------|
| body_volume_estimated | body_width_mm * body_depth_mm * avg_kidney_height | Оценочный объем тела |
| kidney_left_density_ratio | kidney_left_volume_cm3 / kidney_left_length_mm | Плотность левой почки |
| kidney_right_density_ratio | kidney_right_volume_cm3 / kidney_right_length_mm | Плотность правой почки |
| spine_to_body_ratio_x | spine_center_x / body_width_mm | Отношение координаты позвоночника к ширине тела |
| spine_to_body_ratio_y | spine_center_y / body_depth_mm | Отношение координаты позвоночника к глубине тела |
| body_com_to_spine_distance | sqrt((body_com_x - spine_center_x)² + (body_com_y - spine_center_y)²) | Расстояние между центром масс и позвоночником |
| kidney_left_spine_interaction | kidney_left_to_spine_distance * kidney_left_volume_cm3 | Взаимодействие левой почки и позвоночника |
| kidney_right_spine_interaction | kidney_right_to_spine_distance * kidney_right_volume_cm3 | Взаимодействие правой почки и позвоночника |
| body_size_index | sqrt(body_width_mm² + body_depth_mm²) | Индекс размера тела |
| kidney_position_index_left | sqrt(kidney_left_center_x_rel² + kidney_left_center_y_rel² + kidney_left_center_z_rel²) | Позиционный индекс левой почки |
| kidney_position_index_right | sqrt(kidney_right_center_x_rel² + kidney_right_center_y_rel² + kidney_right_center_z_rel²) | Позиционный индекс правой почки |
| volume_to_area_ratio_left | kidney_left_volume_cm3 / (body_area_mm2 / 100) | Отношение объема левой почки к площади тела |
| volume_to_area_ratio_right | kidney_right_volume_cm3 / (body_area_mm2 / 100) | Отношение объема правой почки к площади тела |
| relative_volume_sum | (kidney_left_volume_cm3 + kidney_right_volume_cm3) / body_width_mm | Сумма относительных объемов почек |
| kidney_separation_angle | arccos((left_vector · right_vector) / (|left| * |right|)) | Угол между почками относительно позвоночника |

## 4. Целевые переменные

### 4.1 Описание целей
Модель предсказывает смещение почек по шести осям:

| Цель | Описание | Единицы | Ожидаемый диапазон |
|------|----------|---------|-------------------|
| kidney_left_delta_x | Смещение левой почки по оси X | мм | -20...+20 |
| kidney_left_delta_y | Смещение левой почки по оси Y | мм | -10...+10 |
| kidney_left_delta_z | Смещение левой почки по оси Z | мм | -15...+15 |
| kidney_right_delta_x | Смещение правой почки по оси X | мм | -20...+20 |
| kidney_right_delta_y | Смещение правой почки по оси Y | мм | -10...+10 |
| kidney_right_delta_z | Смещение правой почки по оси Z | мм | -15...+15 |

### 4.2 Клиническая интерпретация
- **X-смещение**: Боковое смещение (лево-право)
- **Y-смещение**: Передне-заднее смещение
- **Z-смещение**: Краниокаудальное смещение (голова-ноги)

## 5. Архитектура ансамбля

### 5.1 Базовые модели

#### RandomForest
- **Параметры**: n_estimators=500, max_depth=10, random_state=42
- **Роль**: Основная модель для большинства целей
- **Преимущества**: Нелинейность, устойчивость к выбросам

#### Lasso
- **Параметры**: alpha=0.1, random_state=42
- **Роль**: Регуляризация, отбор признаков
- **Преимущества**: Интерпретируемость, борьба с мультиколлинеарностью

#### Ridge
- **Параметры**: alpha=1.0, random_state=42
- **Роль**: Сглаживание, стабилизация
- **Преимущества**: Устойчивость к мультиколлинеарности

#### GradientBoosting
- **Параметры**: n_estimators=200, learning_rate=0.1, max_depth=3, random_state=42
- **Роль**: Нелинейные взаимодействия
- **Преимущества**: Высокая точность, градиентная оптимизация

### 5.2 Оптимизация весов

#### Метод оптимизации
- **Алгоритм**: L-BFGS-B (Limited-memory BFGS with bounds)
- **Целевая функция**: Минимизация MAE на валидационном наборе
- **Ограничения**: Веса неотрицательные, сумма = 1

#### Процесс оптимизации
1. Разделение данных: train (80%), validation (20%)
2. Обучение каждой базовой модели на train
3. Предсказание на validation
4. Оптимизация весов для минимизации MAE
5. Финальное обучение на полном наборе с оптимизированными весами

## 7. Валидация и метрики

### 7.1 Метрики качества

#### Основные метрики
- **MAE (Mean Absolute Error)**: Средняя абсолютная ошибка
- **RMSE (Root Mean Square Error)**: Корень из среднеквадратичной ошибки
- **R² (Coefficient of Determination)**: Коэффициент детерминации

#### Клинические метрики
- **Accuracy <5mm**: Доля предсказаний с ошибкой менее 5 мм
- **Accuracy <10mm**: Доля предсказаний с ошибкой менее 10 мм
- **Max Error**: Максимальная ошибка предсказания
- **Outliers >20mm**: Доля выбросов с ошибкой более 20 мм
