- **Интеграция**: Добавлены как средние значения (нет общих ключей)

## Архитектура интеграции

### 1. Автоматическое обнаружение источников
```python
# Проверка наличия файлов
if os.path.exists('data/vybor_unified_features.csv'):
    vybor_df = pd.read_csv('data/vybor_unified_features.csv')
if os.path.exists('data/kits19_medical_grade_features.csv'):
    kits19_df = pd.read_csv('data/kits19_medical_grade_features.csv')
```

### 2. Умное объединение данных
- **Поиск общих ключей**: case_id, patient_id, full_name, patient_name
- **Graceful degradation**: при отсутствии ключей добавляются средние значения
- **Конфликт имен**: автоматические префиксы для предотвращения коллизий

### 3. Специализированная очистка
- **Vybor**: фильтрация медицинских признаков почек
- **KiTS19**: обработка онкологических характеристик
- **DICOMS**: анатомические измерения и объемы

### 4. Гибкое управление
```bash
# Все источники (по умолчанию)
python src/models/train_random_forest.py

# Без DICOMS
python src/models/train_random_forest.py --no-dicoms
```
