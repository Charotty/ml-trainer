# Диссертационный пакет документации (автоматически собран по репозиторию)

## Назначение
Этот набор документов предназначен для включения в диссертацию и описывает:
- историю разработки проекта предсказания смещения почек;
- эволюцию архитектуры и решений (по фактическим файлам проекта);
- математический/инженерный смысл признаков (features), целевых переменных (targets) и параметров моделей;
- воспроизводимый порядок запуска обучения/инференса и API.

## Границы достоверности и источники
Документы ниже сформированы на основе следующих артефактов текущей рабочей копии:
- исходный код в `src/`, `models/phase1/`, `scripts/`;
- результаты экспериментов в `results/`;
- существующая документация в `docs/` и `docs/archive/`;
- git-история данного репозитория.

### Важно про Phase 2
В текущей версии репозитория отсутствует папка `enhanced_models/phase2` и файлы, описанные в ряде документов (например, `feature_pipeline.py`, `dynamic_adaptive_ensemble.py`). 
При этом:
- метрики Phase 2 присутствуют в `results/phase2/*.csv`;
- подробное описание Phase 2 присутствует в `docs/archive/README_ENHANCED_PRODUCTION.md` и `docs/PROJECT_COMPLETE_GUIDE.md`.

В диссертационном пакете Phase 2 описан как **экспериментальная/архивная фаза**, восстановленная по результатам и архивной документации. Это сделано намеренно, чтобы не утверждать наличие кода, которого нет в поставке.
